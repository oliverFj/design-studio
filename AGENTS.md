# Stade for agenter

Ved arbejde på Stade bruges `stade` som projekt-id. Kald Stade-MCP's `get_onboarding` med projekt-id og de relevante opgavetyper, før du vælger fremgangsmåde. Brug flere typer, når opgaven går på tværs. Ved arbejde i et tilknyttet produkt bruges dets registrerede id og lokale anvisninger.

Læs de guideafsnit, der gælder for opgaven. Uden Stade-MCP bruges [opgavevalget og de fælles rammer](docs/AGENT-ONBOARDING.md) lokalt.

Genbrug eksisterende roller og controllere, og bevar grænsen mellem produkt, tema og fælles runtime. Byg efter kode-, tema- og ressourceændringer, og brug den relevante kontrolvej. Vedligehold dokumentationen på bestilling eller ved konkret væsentlig teknisk risiko. Svar kort på dansk med ændring, faktisk kontrol og væsentlige begrænsninger.
